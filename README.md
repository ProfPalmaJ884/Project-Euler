# Project-Euler
Python solutions for Project Euler mathematical and computational problems.

Este repositorio contiene mis soluciones en **Python** para los problemas de [Project Euler](https://projecteuler.net/). 

El objetivo es practicar el pensamiento computacional, la optimización de código y la aplicación de teoría de números a la programación.

---

## Tecnologías y Conceptos Aplicados:
* **Lenguaje:** Python 3
* **Áreas:** Lógica matemática, secuencias recursivas, teoría de números, optimización de bucles.
